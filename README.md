# Offline AI Customer Support Chat UI (PyQt5)

A modern, desktop customer support application built using **Python and PyQt5** that interfaces with a local **n8n AI Agent workflow** backed by a locally hosted **Ollama LLM (`gemma4:26b`)**.

---

## 1. Project Overview

This desktop application provides an offline conversational customer-support interface for querying orders, checking delivery dates, resolving product issues, and creating complaint tickets.

### Highlights
- **100% Offline Architecture**: Connects directly to local Docker/WSL `n8n` (`http://localhost:5678`) and local `Ollama` (`http://127.0.0.1:11434`). Zero cloud API keys or external internet requests needed.
- **Asynchronous & Responsive**: Built with PyQt5 `QThread` workers, signals, and slots. The UI never freezes or stutters while local 26B parameter models perform inference.
- **Session Continuity**: Preserves conversation `sessionId` across turns so the AI Agent retains order IDs, emails, and complaint context without asking the customer to repeat themselves.
- **Complaint & Order Verification**: Accurately highlights verified order details and real ticket IDs (`TKT-...`) generated by the n8n `complaint_tickets` Data Table tool. Never invents fake IDs.
- **Live Health Diagnostics**: Background service monitors local `n8n` and `Ollama` status in real time and provides actionable troubleshooting if a service is down or a workflow is unpublished.
- **Executive UI/UX**: Sleek dark slate styling, multi-line auto-wrapping text area (`Enter` to send, `Shift+Enter` for new line), welcome screen with suggested question cards, persistent chat history, and an interactive Settings dialog.

## 5. Using the Application

### 1. Asking Order-Related Questions
Click one of the suggested cards on the welcome screen or type:
- *"What is my order status for ORD1001?"*
- *"Where is my order ORD1001?"*

The AI Agent queries the `orders` Data Table in n8n and returns the product (`Wireless Mouse`), shipping status (`Shipped`), amount (`₹799`), and estimated delivery date (`2026-10-15`).

### 2. Registering Complaints
Describe your issue naturally:
- *"My product arrived damaged for order ORD1001. My email is customer@example.com."*

The AI Agent validates the details, inserts a new record into the `complaint_tickets` table, and returns a verified ticket ID formatted as `TKT-...`. The UI highlights this with a green verification card.

### 3. Keyboard Shortcuts
- **Enter**: Send message
- **Shift + Enter**: Insert new line

### 4. Settings & Connection Diagnostics
Click **⚙ Settings** in the bottom of the sidebar to:
- Switch between **Production** and **Test** endpoints
- Edit the webhook URL or Ollama server URL
- Adjust request timeouts (up to 600s)
- Click **Test Connection Now** to perform immediate connectivity diagnostics
